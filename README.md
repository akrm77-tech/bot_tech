## ⚙️ التثبيت والتشغيل

```bash
# 1. استنساخ المستودع
git clone https://github.com/your-username/bot_tech.git
cd bot_tech

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. إعداد المتغيرات (أنشئ ملف .env)
BOT_TOKEN=your_token_here
PLATFORM_URL=https://alway3alatiqny3.netlify.app/

# 4. التشغيل
python bot.py
```
